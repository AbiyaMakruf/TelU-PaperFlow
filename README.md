# Paperflow

Paperflow is an editorial workflow platform for conference papers. It replaces per-conference Google Forms and spreadsheets with configurable submissions, assignments, editorial checks, versioned files, reviewer approval, and progress reporting.

## Stack

- Laravel 12
- PostgreSQL on Supabase
- Private Supabase Storage
- Blade, Alpine.js, Tailwind CSS, and Vite
- Gmail SMTP through queued Laravel mail

Implementation and local setup instructions will be expanded as each product milestone lands.
